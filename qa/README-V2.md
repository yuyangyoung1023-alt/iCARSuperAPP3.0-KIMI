# iCAR Claw APP V2.0 可交互 Demo

## 首页动效与功能预览 · 2026-09-05

当前 iCARSuperAPP2.0 采用 16:9 车机横屏首页，支持在 iCAR 趣玩、场景技能、推荐场景和我的场景之间动态切换。点击中央“i”直接进入语音交互；右下角设置图标进入 MA 相关能力管理。

趣玩首页重点展示“情景互动与品牌彩蛋、惬意午休、测测、沿途识物”四项能力，每张卡片提供功能说明、示例说法和快捷语音体验。“更多趣玩”仅展示其余五项内容，避免重复。首页支持暂停动效以及系统减少动态效果偏好。

首页动效资源位于 assets/home-motion.css 和 assets/home-motion.js，需与 index.html 一起保留。

本机预览可运行 `python3 -m http.server 8766 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8766/`。

普通交互可直接打开 `index.html` 使用；语音体验需要通过 HTTPS 或本地网页服务访问。首页按 16:9 车机屏幕设计，面向 1280×720、1600×900 与 1920×1080 等横屏尺寸。语音识别是否可用仍需在演示电脑与浏览器上确认，不能仅由页面尺寸或 HTTPS 推断。

当前工程已经升级为可安装的 PWA Web App，包含应用清单、离线缓存、横屏启动配置与 GitHub Pages 自动部署流程。发布后可以在浏览器中选择“安装应用”或“添加到主屏幕”，以独立窗口运行。

## 建议演示路径

1. 首页左侧「主动服务」分别展示「推荐场景」与「我的场景」中已经启动的服务；点击“关闭”后，该服务立即从首页移除，但不会删除配置。
2. 点击推荐场景会打开只读规则详情，以与“我的场景”一致的排版说明触发条件、执行内容和执行方式；推荐场景不展示变更记录，只支持返回、开启或关闭，规则始终由 iCAR 维护。
3. 点击我的场景卡片会先打开只读详情，展示触发条件、执行内容、执行方式与变更记录。只有再点“编辑场景”才进入顶部居中的语音修改卡，不会因查看详情直接申请麦克风。
4. 首页右侧通过六个 TAB 查看车辆控制、出行助手、车辆知识问答、生活服务、媒资娱乐和 iCAR 趣玩。当前共 37 张同规格技能卡，在当前类别内滚动浏览，不再设置独立的大视频占位。
5. 点击任意技能卡片会打开统一的详情弹窗：顶部说明用户价值，中部为可播放、暂停的专属场景演示，底部固定“返回 / 立即语音体验”。车控显示座舱状态，出行显示地图与路线，生活服务显示订单、座位或票务，媒资显示封面、波形与播放进度，趣玩显示对应主题卡；详情中不重复展示任务编排步骤。
6. 点击首页顶部语音入口或技能卡片中的“语音体验”后，页面会申请电脑麦克风权限。识别到语音只生成草稿，不会立即执行。
7. 用户可以点击“继续说”补充后半句；只有点击“确认说完了”后，Master Agent 才开始任务编排，并按“等待 → 执行中 → 完成”自动逐项向下推进。该确认仅代表输入结束，不替代支付或高风险操作的业务确认。
8. 自定义场景的新建与编辑遵循“聆听 → 展示结构化理解 → 确认说完了 → 自动检查 → 确认规则 → 保存”，误停顿不会直接修改场景。新建与编辑都会检查推荐场景和我的场景；完全一致时复用或调整、相似时明确选择、互斥冲突时阻断保存。编辑只修改当前场景，不会合并到其他场景。
9. iCAR 趣玩的 9 项能力分别使用彩蛋、星座、塔罗、今日签、氛围配色、视觉扫描、海龟汤、午休和日历计算主题，从演示、聆听、执行到结果保持各自视觉。
10. 「视野受阻主动恢复、身份识别与偏好恢复、导航前全景预检、沿途景点介绍、停车推荐、车辆状态异常守护、情景化迎宾、记忆迎宾」等无需用户先开口的能力统一归入推荐场景；「路途待办提醒」作为可语音创建的我的场景模板。
11. 在主动服务管理页使用「全部、安全守护、出行导航、上车陪伴、内容推荐、我的场景」标签快速筛选。习惯建议只在已登录、Memory 开启且存在相关行为、舒适与媒体记录时出现，依据实时读取当前记录；删除依据、清空记忆或退出后不再展示。查看依据和预览后，可新建或合并到已有我的场景。
12. 使用「创建场景」，体验语音生成、确认、查重与本地保存：完全一致时复用已有场景；相似推荐场景可保留差异继续创建；相似我的场景可合并或明确保留差异；同一触发条件下存在互斥动作时阻断并提示调整。缺少权限时先保存为关闭状态，补齐依赖后开启。我的场景支持删除确认、10 秒撤销与最近 20 条变更记录。
13. 在首页直接说“导航回家，再放点轻松的歌”，确认说完后体验多任务理解和自动编排；第三方服务完成授权后会恢复原任务。
14. 在「我的记忆」体验六类筛选、单条编辑删除、批量管理与清空。
15. 在「账号、隐私与权限」关闭 Memory、座舱环境感知或车外环境感知，再返回首页及主动服务查看实时降级。
16. 退出账号，查看账号资产隐藏；重新登录同一账号后恢复原状态。
17. 「语音与唤醒」包含语音助手总开关、自定义唤醒词、自定义应答词、主驾全时免唤醒、智能免唤醒、连续对话时长（关闭 / 10s / 30s / 60s）和方言模式；关闭总开关后子项灰显但保留原配置。「更多」及其中的语音技能说明已移除。隐私政策统一在「账号、隐私与权限」查看，访客及关闭语音助手时仍可阅读；阅读或返回不改变任何权限，不申请麦克风。
18. 「角色引擎」承接实车播报音色，提供甜美女声、温柔女声、阳光男声、成熟男声，以及性格、表达方式、主动程度和称呼。选择后先更新草稿和预览；保存才生效，离开前可保存或放弃修改。网页试听使用浏览器可用系统声音，不等同于实车专有音色。

## 最终技能目录

- 车辆控制（5）：感受类控车、描述类控车、其他模糊类车控、多任务控车、氛围灯助手。
- 出行助手（5）：常用地直达、模糊 POI 搜索、目的地发现与精准到达、多日行程规划、生活搜索。
- 车辆知识问答（4）：车况查询、故障灯问询、车辆知识问答、用车问题助手。
- 生活服务（7）：餐饮与商品下单（外卖）、餐厅订座与聚餐安排、电影票、景点、出行、住宿、停车缴费。卡片同时标明餐饮美食、文娱票务、旅行助手、停车缴费二级分类。
- 媒资娱乐（7）：音乐推荐与搜索、哼唱找歌、音乐信息查询、影视推荐与查询、线索找内容、播放内容问答、新闻播报。
- iCAR 趣玩（9）：情景互动与品牌彩蛋、测测、塔罗牌、神算子、氛围制造机器、沿途识物、海龟汤、惬意午休、日历与计算器。

## V12 更新：技能清理与统一隐私入口

- 移除「旅途影像」技能及对应演示、语音入口；其他趣玩能力保留，不删除用户自行创建的场景或记忆。
- 移除语音设置中的「语音技能说明」及空的「更多」区。
- 隐私政策仅在「账号、隐私与权限」提供一个入口，采用只读说明，不新增总授权或重复开关；Memory、身份识别、感知及第三方授权继续分别管理。
- 页面说明区分系统/浏览器麦克风许可与 Demo 业务权限。关闭语音助手不会代替用户撤销其他权限，阅读政策不等于授权。
- 更新离线缓存版本；保持已交付的 PRD 文件不变。

「夸一夸」已从 iCAR 趣玩迁入推荐场景，默认关闭，由用户在推荐区开启；开启后依赖已登录账号、Face ID 或声纹身份识别以及座舱人员感知。

主动服务目录已移除“乘员不适主动关怀、最优模式推荐、空气净化、哨兵守护”对应卡片；历史浏览器状态会在加载时自动迁移并隐藏这些旧卡片。

「氛围灯助手」会从本次语音中的颜色、心情和场景关键词动态生成主辅色、亮度和渐变周期。例如“赛博蓝、科技感”与“森林露营、自然感”会得到不同配色，而不再固定复用落日示例。

生活服务中的“确认说完了”只确认语音需求已经说完。付款、订座、购票、订房和停车缴费会展示具体对象、数量、时间与示例费用，支持单独确认、取消或用语音修改；缺少必要信息会先请用户补充。修改后生成新版本，并更新受影响字段及示例费用，确认后只模拟提交和回执，不发生真实订单或扣款。商户、场次、房源及价格均为内置演示数据，字段会标明来源。氛围制造机器也需确认配色、音乐与回应方案后才显示演示应用完成，不改变已保存的角色设置。

我的场景在保存前展示本次修改前后对照，保存后历史保留字段明细；没有有效改动或取消时不新增变更记录。语音中说“结束对话”等明确结束指令后，仍须点击“确认说完了”才结束本轮会话；“停止播放音乐”等具体业务指令不会被当成退出。

## 状态说明

Demo 使用浏览器本地存储保留状态，刷新后仍会恢复；退出仅隐藏账号资产，不删除数据。清空的记忆数组会保持为空，不在刷新时重新生成。损坏的旧状态会先备份到 `icarClawV2.recovery.<时间戳>` 再恢复初始结构。浏览器不允许存储时，只能保留本次打开期间的状态。若需从初始状态重新演示，请清除此页面的站点数据或在浏览器控制台执行 `window.localStorage.removeItem('icarClawV2')` 后刷新。

本 Demo 为单文件前端原型，图标与场景插画均为内置 SVG。每张技能卡的演示是独立的 CSS/SVG 动态媒体脚本，支持播放和暂停，不是实车录制视频。第三方授权、Face ID/声纹录入、车控、支付、订单与账号同步是可交互模拟，不采集真实生物特征，也不连接真实车辆或生态服务。

麦克风采集和浏览器语音识别是真实浏览器能力：仅由用户点击语音入口、编辑/新建、继续说或重试触发，不在打开页面或查看规则时启动。Demo 本身不保存音频；浏览器的语音识别服务可能依赖网络及其服务方。免唤醒、方言混合识别和车内分音区硬件效果不能由本网页等同复刻。

V11 的主要补齐项包括：逐任务授权暂停/恢复、业务确认与取消、账号资产隔离、Memory 空态与依赖降级、身份识别依赖、场景编辑查重/删除撤销/历史、角色草稿与系统声音试听、测测/塔罗/海龟汤多轮卡片。功能回归与浏览器界面检查不替代真实麦克风、车控接口或生态支付联调验收。

## 麦克风运行要求

浏览器只允许安全页面使用麦克风。请使用最新版 Chrome 或 Edge，并通过以下任一方式打开：

- 上传到 GitHub Pages 后通过 `https://` 地址访问；
- 在文件目录启动本地网页服务，通过 `http://localhost` 访问。

不建议直接双击 `index.html` 以 `file://` 方式打开，因为部分浏览器不会向本地文件开放麦克风和语音识别能力。首次点击首页语音入口、“创建场景”、“编辑场景”或“语音体验”时，请按浏览器提示决定是否允许麦克风。查看“我的场景”详情不申请权限。拒绝授权、识别不可用或未听清时，界面保留重试/返回入口，不假装执行成功。

## GitHub Pages 发布

工程已包含 `.github/workflows/pages.yml`。上传到 GitHub 仓库并推送到 `main` 分支后：

1. 进入仓库的 Settings → Pages；
2. 将 Source 设为 GitHub Actions；
3. 等待 `Deploy iCAR Claw Demo` 工作流完成；
4. 使用 GitHub 提供的 `https://<用户名>.github.io/<仓库名>/` 地址访问。

工作流只部署 `index.html`、`sw.js`、`manifest.webmanifest`、`.nojekyll` 与 `assets/`；不会发布 PRD、复核文件、ZIP 或历史备份目录。更新推送至 `main` 后，GitHub Actions 会自动部署网页。

Pages 的 HTTPS 环境满足麦克风安全上下文条件，但系统权限、站点权限、浏览器 Web Speech 支持和识别服务网络仍会影响结果，HTTPS 本身不能保证麦克风/识别必定可用。离线缓存仅支持页面和交互展示，不保证离线语音识别；更新时只清理本 Demo 前缀的旧缓存。

页面统一使用用户能理解的能力描述，不展示研发阶段、落地范围或内部限制标签；缺少权限时只说明需要用户开启的能力。
