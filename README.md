## 运行

双击 `启动V3.command`，会启动仅本机访问的服务并打开浏览器。保持终端窗口打开；关闭时按 Control+C。

也可在此目录运行：

```sh
python3 run.py
```

只看界面可直接打开 `index.html`。语音需通过 localhost 或 HTTPS，并依赖浏览器的麦克风与语音识别支持。推荐在实际演示电脑上用 Chrome 检查真实收音。

- `assets/brand/`：V25 四视角、卡基狗及原会话页面参考；首页只使用原始前45°图和卡基狗，未采用参考图中的其他车辆或气泡；新增 pavilion-v31.png 是从参考图提取的纯空间背景。
- `assets/videos/`：3 个原 MP4；资源来源、大小、SHA-256 见 `qa/resources.json`。
- `qa/scene-mapping.json`：场景映射快照；`QA.md`：逐项验收与限制；`CHANGELOG.md`：变更清单；`BASELINE-AUDIT.md`：基线审计。

## 后续视频接口

每个场景支持 `video` 和 `poster` 字段。将本地视频放入 `assets/videos/`，在场景目录填写相对路径即可使用真实播放器。MA 的 `futureVideo` 记录建议接入路径；目前 `video` 为空，因此显示明确标注的概念占位内容。三个业务视频不能替换为这些占位内容。

## 能力边界及已知限制

这是可交互 Demo。真实车控、停车支付、账号服务、声纹/人脸、长期 Memory 与外部订座购票没有新增接入；V2 内置数据与模拟授权逻辑保留。五域十意图展示不代表已实现十任务连续规划。

对于 V2 没有专门技能的新增场景，「立即体验」进入原全局语音流程，不虚构专用执行能力；详见场景映射。新预设仅提供演示规则，沿用原权限检查。

真实麦克风收音、联网 ASR、可听 TTS、真实车辆和外部服务未实测。自动化测试使用明确的 ASR 测试桩，只验证界面和状态机。原引擎对不同时间表达的等价归一有限，例如 `周末 08:00` 与 `周末 · 早上8点` 不保证识别为相同触发条件。

PWA 离线缓存界面与主视觉；大型视频保留本地服务读取，不承诺关闭服务器后仍可离线播放全部 MP4。首次打开和视频演示请保持本地服务运行。
